一个基于 FastAPI + Jinja2 服务端渲染的个人博客。  
用 Markdown 写文章，记录零碎的想法，也欢迎留下评论和留言。

## 这里有什么

| 内容 | 说明 |
|---|---|
| 📝 **文章** | Markdown 写作，支持标签、归档、搜索、目录、相关文章和 RSS |
| 💬 **动态** | 记录零碎的想法和日常 |
| ✍️ **留言** | 登录后在留言板留下想说的话 |
| 💭 **评论** | 文章和动态都支持评论，审核后展示 |
| 🌙 **阅读** | 暗色模式、响应式布局、代码高亮和代码复制 |
| ⚙️ **后台** | 管理文章、动态、评论、留言和图片；邮箱 + 密码 + 验证码登录，可选 TOTP |

## 技术

`FastAPI` · `Jinja2` · `HTMX` · `MySQL` · `SQLAlchemy` · `Alembic` · `Markdown` · `Pygments` · `Pillow`
