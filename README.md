一个前后端分离的个人博客：**Next.js 16 前台 + FastAPI 后端**。  
用 Markdown 写文章，记录零碎的想法，也欢迎留下评论和留言。

## 这里有什么

| 内容 | 说明 |
|---|---|
| 📝 **文章** | Markdown 写作、标签、目录、相关文章、归档、搜索和 RSS |
| 💬 **动态** | 记录零碎的想法和日常 |
| ✍️ **互动** | 登录后评论、留言；评论审核后展示 |
| ⚙️ **后台** | 文章、评论、动态、用户、图片与安全设置；邮箱验证码 + 可选 TOTP |
| 🎨 **体验** | 响应式布局、亮/暗色切换、文章目录与阅读优化 |
| 📡 **订阅** | RSS、sitemap 和 robots.txt |

## 技术

- 前台与后台日常页面 Next.js 16 + React 19 + TypeScript
- 后端 FastAPI + SQLAlchemy + MySQL
- 自托管在 Nginx + systemd 上
